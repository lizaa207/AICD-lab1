# Лабораторная работа №1. Вариант 2. Матрицы

Шаблонный класс матриц произвольного размера на C++17.  
Тип элемента матрицы задаётся параметром шаблона `T`.

## Возможности

- Шаблонный класс `Matrix<T>`: матрица произвольного размера на динамическом массиве.
- Поддержка типов элементов:
  - `int`
  - `float`
  - `double`
  - `std::complex<float>`
  - `std::complex<double>`
- Конструктор с параметрами: размеры матрицы и значение для заполнения.
- Конструктор со случайным заполнением (размеры матрицы, нижняя и верхняя границы). Для комплексных чисел границы применяются отдельно к действительной и мнимой частям.
- Чтение и запись элемента по индексам через `operator()` с проверкой границ.
- Операторы `+` и `-` для матриц (и `+=`, `-=`).
- Оператор `*` для умножения матриц.
- Умножение матрицы на скаляр с обеих сторон (`matrix * scalar` и `scalar * matrix`), а также `*=`.
- Деление матрицы на скаляр (`/` и `/=`).
- Метод `Trace()` — след матрицы.
- Операторы сравнения на равенство и неравенство; элементы сравниваются с точностью `kEpsilon`.
- Оператор вывода в поток `std::ostream` без использования C-шных потоков.
- Методы `GetRows()` и `GetCols()` — размеры матрицы.

## Решаемая задача

**Вариант 2.** Привести заданную квадратную матрицу A к нижнетреугольному виду, то есть разложить её на нижнетреугольную матрицу L и верхнетреугольную матрицу U, произведение которых равно исходной матрице: `L * U = A` (LU-разложение).

Решение вынесено в функцию `DecomposeLu()`, определённую вне класса. Используется метод Гаусса без перестановок строк:

- `L` — нижнетреугольная матрица с единицами на диагонали;
- `U` — верхнетреугольная матрица, которая получается из `A` последовательным обнулением элементов под диагональю;
- множитель, на который умножается ведущая строка при обнулении, записывается в `L`.

Пример для матрицы `|2 1; 4 3|`: множитель `4 / 2 = 2`, тогда `U = |2 1; 0 1|`, `L = |1 0; 2 1|`, и `L * U = |2 1; 4 3|`.

Если на диагонали встретился нулевой элемент, разложение без перестановок строк невозможно и выбрасывается `std::domain_error`. Для целочисленных типов функция не компилируется (`static_assert`): целочисленное деление дало бы неверный результат.

## Что выводит программа

В `main()` для каждого из пяти типов (`int`, `float`, `double`, `std::complex<float>`, `std::complex<double>`) создаются случайные матрицы и демонстрируются все конструкторы, операторы и методы, а также обработка ошибок. Затем для `double` и `std::complex<double>` выполняется LU-разложение случайной матрицы 4x4: выводятся `A`, `L`, `U`, произведение `L * U` и результат сравнения `L * U == A`.

## Обработка ошибок

- `std::out_of_range` — обращение к элементу по несуществующему индексу.
- `std::invalid_argument` — нулевой размер матрицы; сложение и вычитание матриц разных размеров; умножение матриц с несогласованными размерами; деление на ноль; след и LU-разложение неквадратной матрицы; нижняя граница больше верхней в случайном конструкторе.
- `std::domain_error` — нулевой ведущий элемент при LU-разложении.

## Особенности реализации

- Элементы хранятся в одном динамическом массиве по строкам: элемент `(row, col)` лежит по индексу `row * cols + col`.
- При присваивании сначала создаётся и заполняется новый массив, и только потом освобождается старый.
- В случайном конструкторе при исключении выделенная память освобождается.
- Элементы сравниваются с точностью `Matrix<T>::kEpsilon` (статическая константа, `1e-6`): модуль разности элементов не должен превышать эту величину. Для `int` сравнение получается точным.
- Для целых типов случайные значения генерируются через `std::uniform_int_distribution`, для вещественных — через `std::uniform_real_distribution`.
- Проверка типов выполняется на этапе компиляции через шаблоны, перегрузки `AbsValue` и `GetRandom` и `static_assert`; `typeid` и `dynamic_cast` не используются.
- Компиляторные предупреждения:
  - Clang/GCC: `-Wall -Wconversion -Wextra -Wpedantic`;
  - MSVC: `/W4`.
